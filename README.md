# ESA Code Assignment 1 — The Little Taco Shop

This project is **Assignment 1 for ESA Code**, a coding club for engineering
students at the Ghana Communication Technology University (GCTU).

Your task is to build a three-page website for **The Little Taco Shop** using
HTML. Reference images showing the expected appearance of the three pages will
be provided in the [`Resources`](./Resources) folder. Study those images and
recreate the content and structure as closely as possible.

## Project aim

The purpose of this assignment is to help you turn a visual reference into a
working, well-structured website. By the end of the assignment, you should be
able to create multiple HTML pages, connect them with navigation links, present
different types of content, and organise a small website using semantic HTML.

After successfully completing the project, your website should:

- contain a home page, store-hours page, and contact page;
- allow users to move between all three pages;
- display the shop's information, menu, opening hours, and contact details;
- include the images and text shown in the supplied references;
- use meaningful HTML elements and a clear document structure; and
- work correctly when opened in a web browser.

## Pages to build

### 1. Home page — `index.html`

The home page should include:

- the shop heading and navigation menu;
- a taco shop image with descriptive alternative text;
- an **About LTS** section;
- an expandable taco-trivia question;
- an **Our Menu** table; and
- a back-to-top link and footer.

### 2. Store hours page — `hours.html`

The store-hours page should include:

- the page heading and navigation menu;
- an image with a caption or description;
- the days and times the shop is open; and
- a back-to-top link and footer.

### 3. Contact page — `contact.html`

The contact page should include:

- the page heading and navigation menu;
- an image with descriptive alternative text;
- a contact form for a visitor's name, email address, and message;
- **Send** and **Reset** buttons;
- the shop's address and clickable telephone number; and
- a back-to-top link and footer.

## HTML concepts you will practise

Completing this assignment will help you understand and use:

- the basic HTML document structure (`doctype`, `html`, `head`, and `body`);
- page metadata, titles, and viewport settings;
- semantic layout elements such as `header`, `main`, `section`, and `footer`;
- headings, paragraphs, line breaks, and horizontal rules;
- ordered or unordered lists and description lists;
- links between pages, links to sections on a page, back-to-top links, and
  telephone links;
- images, relative file paths, and accessible `alt` text;
- tables, table headings, rows, cells, `rowspan`, and `colspan`;
- interactive disclosure elements using `details` and `summary`;
- forms, labels, inputs, text areas, fieldsets, legends, and buttons;
- element attributes such as `id`, `class`, `href`, `src`, `for`, and `name`;
  and
- HTML comments, indentation, nesting, and readable code organisation.

## Getting started

1. Sign in to GitHub and **fork this repository** to your own account.
2. Clone your fork to your computer:

   ```bash
   git clone https://github.com/YOUR-USERNAME/REPOSITORY-NAME.git
   ```

3. Open the cloned folder in your code editor.
4. Review the three reference images in the `Resources` folder.
5. Build or complete `index.html`, `hours.html`, and `contact.html`.
6. Open `index.html` in a browser and test every page and link.
7. Save your progress with Git and push it to your fork:

   ```bash
   git add .
   git commit -m "Complete ESA Code assignment 1"
   git push origin main
   ```
